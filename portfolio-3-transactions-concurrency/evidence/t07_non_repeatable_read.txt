T7: a leaderboard is read twice while a vote and a like arrive
==============================================================

The reader reads a post's like counter (a row value) and counts its votes (a set of rows),
then a writer commits one new like and one new vote, then the reader repeats both reads in
the same transaction. A changed counter is a non-repeatable read; a changed count is a phantom.

   0.029s  [reader] first read:  likes_count=0, votes=0
   0.057s  [writer] committed one like (counter +1) and one vote
   0.068s  [reader] second read: likes_count=1, votes=1
